# ST mate

ST mate는 서울과학기술대학교 학생을 위한 학습 플래너입니다. 수강 과목과 일정을 관리하고, 과목별 학습 시간을 기록하며, Gemini 기반 AI 친구 "별이"와 대화할 수 있습니다.

[시연 영상](https://youtu.be/wNtl2eOa6Xc?si=mGrE9HJR88Tgr-Wl)

[발표자료](발표자료.pdf)

## 주요 기능

- eClass 학사 정보와 개인 학습 기록을 결합한 학습 플래너
- 과목·성적·일정·학습 시간을 관리하는 학사/학습 대시보드
- Gemini 기반 AI 학습 친구 "별이"와 대화 및 월간 학습 조언

## 화면별 기능 안내

### 로그인, 사용자 정보 및 화면 이동

- 서울과학기술대학교 eClass 학번과 비밀번호로 로그인합니다. 로그인 성공 시 프로필, 선택한 학기의 과목, 할 일과 기존 학습 기록을 불러옵니다.
- eClass 비밀번호는 로그인 요청에 사용되며 사용자 데이터로 저장하지 않습니다. 앱은 로그인 중인 eClass 세션을 이용해 학사 정보를 조회합니다.
- 좌측 메뉴에서 홈, 수강 과목, 학점 관리, 학습 타이머, 학습 통계 및 분석, 할 일 관리, 별이와 대화 화면으로 이동할 수 있습니다. 메뉴는 접거나 다시 펼칠 수 있습니다.
- 사용자 메뉴의 "내 정보"에서는 eClass에서 가져온 이름, 학번, 학과, 학년, 전화번호, 이메일을 확인할 수 있습니다.
- 사이드바 아래의 학교 홈페이지와 통합정보시스템 링크는 새 창으로 엽니다.
- 로그아웃하면 진행 중인 타이머를 먼저 저장한 뒤 eClass 세션을 정리하고 로그인 화면으로 돌아갑니다. 타이머 저장에 실패하면 데이터 유실을 피하기 위해 로그아웃을 중단하고 다시 저장할 수 있도록 상태를 유지합니다.

### 홈

- 별이 인사 이미지와 함께 학습 현황을 확인하는 시작 화면입니다.
- **주간 일정**에는 오늘부터 7일간의 개인 일정과 eClass 할 일을 날짜별로 표시합니다. 날짜를 누르면 할 일 관리 화면에서 해당 날짜의 상세 일정을 볼 수 있습니다.
- **오늘의 할 일**에는 오늘 날짜에 해당하는 개인 일정과 eClass 할 일을 완료 여부와 함께 표시합니다.
- **오늘의 시간표**에는 로그인한 사용자의 현재 요일 수업을 표시합니다. 시간표는 과목의 학기와 수업 요일 정보를 이용합니다.
- 홈에서 일정 추가를 누르면 오늘 날짜가 선택된 상태로 개인 일정 입력 창을 엽니다. 할 일 관리 화면으로 바로 이동하는 링크도 제공합니다.

### 수강 과목

- 연도와 학기를 선택해 과목을 구분해서 확인합니다. 학기 종류는 1학기, 여름학기, 2학기, 겨울학기입니다.
- 선택한 학기의 eClass 과목을 다시 불러오며, 불러온 데이터는 Firebase에 저장됩니다. 일시적인 조회 오류가 발생하면 이미 저장된 과목을 화면에 남기고 오류 안내를 표시합니다.
- 선택한 학기의 신청 학점 합계, 주간 시간표, 과목 목록을 제공합니다. 목록에는 과목명, 과목 코드, 담당 교수, 수업 시간, 학점이 표시됩니다.
- 주간 시간표는 월요일부터 일요일까지 과목의 요일과 교시를 배치합니다. 일정이 겹치는 수업은 겹침을 알아볼 수 있도록 별도 위치에 표시합니다.
- **직접 추가한 과목**은 과목명, 선택 입력 항목인 과목 코드와 담당 교수, 학점, 하나 이상의 수업 요일·시작 교시·끝 교시를 입력해 등록할 수 있습니다. 학점은 1부터 30 사이의 정수이며 교시는 1부터 16교시 범위입니다. 종료 교시는 시작 교시보다 빠를 수 없습니다.
- 직접 추가한 과목은 수정과 삭제가 가능합니다. eClass에서 가져온 과목은 수강 정보를 임의로 바꾸거나 삭제하지 않도록 관리 버튼을 제공하지 않습니다.
- 수업 시간 입력 행을 여러 개 추가할 수 있어 한 과목에 복수의 주간 수업 시간을 등록할 수 있습니다. 등록·수정 오류나 저장 중 상태는 입력 창에서 안내합니다.

### 학점 관리

- 학기를 선택해 해당 학기의 과목별 성적을 입력하거나 기존 성적을 수정할 수 있습니다. 성적 선택지는 A+, A0, B+, B0, C+, C0, D+, D0, F이며 "미입력"으로 되돌릴 수도 있습니다.
- 성적을 선택하면 Firebase에 즉시 저장하고 계산 결과를 갱신합니다. 저장에 실패하면 이전 선택으로 복원하고 오류를 표시합니다.
- 과목 표에는 과목명, 학점, 성적, 등급별 평점, 해당 과목으로 기록된 누적 공부 시간이 표시됩니다.
- 성적이 입력된 과목을 대상으로 학점 가중 평균을 계산해 **전체 누적 평점**과 **선택 학기 평점**을 4.5 만점, 소수점 둘째 자리까지 표시합니다. 성적이 입력되지 않은 과목은 GPA 계산에서 제외합니다.
- 총 이수 학점은 F를 제외한 성적 입력 과목의 학점을 합산합니다. 130학점을 기준으로 진행 상태를 표시하며, 이는 앱의 진행 표시 기준이지 학교의 공식 졸업 사정 결과는 아닙니다.
- 성적이 입력된 과목이 없으면 GPA 대신 대시를 표시합니다.
- 현재 앱의 성적 선택지는 A+부터 F까지이며, P/F 성적 관리 기능은 포함하지 않습니다.

### 학습 타이머 및 집중 모드

- 현재 학기의 수강 과목을 학습 대상으로 사용합니다. "과목 수정" 창에서 과목을 타이머 목록에 표시하거나 숨길 수 있고, 수강 과목 외에 타이머 전용 과목명을 추가할 수도 있습니다. 이 표시 설정과 타이머 전용 과목은 Firebase에 저장됩니다.
- 과목별 "시작" 버튼으로 측정을 시작하고, 활성 과목의 "중단" 버튼으로 마칩니다. 시작 중인 과목을 바꾸면 기존 세션을 먼저 저장한 뒤 새 세션을 시작합니다.
- 화면에는 오늘의 전체 공부 시간, 현재 학습 중인 과목, 과목별 오늘 공부 시간과 상대 진행 막대를 표시합니다. 저장된 세션은 과목, 시작·종료 시각, 공부 시간으로 기록되어 통계와 성적 화면에 활용됩니다.
- 공부 중이 아닐 때와 공부 중일 때 별이 이미지와 문구가 바뀝니다. 공부 중에는 "공부 시작했네! 별이도 열심히 집중할게.", 대기 중에는 "공부 시작하면 깨워줘... 조금만 잘게."를 표시합니다.
- 집중 허용 앱은 Chrome과 Notion이 기본 선택되어 있고, Discord와 Steam을 추가로 허용할 수 있습니다. 이 설정은 앱 프로세스를 확인하는 기준입니다.
- 허용 목록에 포함되지 않은 지원 앱(Chrome, Notion, Discord, Steam 계열 프로세스)이 실행 중이면 타이머 시작을 막습니다. 공부 중 새로 감지되면 자동 일시정지하고, 해당 앱을 닫거나 허용 설정을 조정한 뒤 "다시 시작"할 수 있습니다.
- 집중 모드는 앱을 강제 종료하거나 모든 컴퓨터 사용을 차단하지 않습니다. 코드에 지정된 앱 프로세스만 확인하며, 그 외 앱은 감지 대상이 아닙니다.
- 세션 저장에 실패하면 저장 대기 상태와 오류를 표시하고 "저장 재시도"를 제공합니다. 1초 미만의 세션은 학습 기록으로 저장하지 않습니다.
- 타이머 화면 하단에는 이번 주 요일별 공부 시간을 간단한 그래프로 보여주고 전체 세션 수와 누적 시간을 표시합니다. "자세히 보기"에서 통계 화면으로 이동합니다.
- 로그인하지 않은 상태에서도 화면의 예시 과목으로 타이머 동작을 미리 볼 수 있지만, 이 미리보기 세션은 Firebase에 저장되지 않습니다.

### 학습 통계 및 분석

- 이번 주, 이번 달, 이번 학기 탭으로 기간을 바꿔 기록을 집계합니다. 기간 계산은 한국 시간 기준입니다.
- 선택 기간의 총 공부 시간, 하루 평균 공부 시간, 연속 공부 일수를 표시합니다. 직전 주·월·학기와 비교할 수 있는 기록이 있으면 공부 시간 증감률도 보여줍니다.
- 첫 번째 막대 그래프는 기간에 따라 주간의 요일별, 월간의 주차별, 학기의 월별 공부 시간을 나타냅니다. 두 번째 그래프는 24시간대별 공부 시간을 보여주며 06시부터 순서대로 확인할 수 있습니다.
- **학습 패턴 분석**은 이번 달 기록에서 공부 시간이 가장 많은 3시간 구간과 요일을 찾아 보여줍니다. 기록이 부족하면 분석을 만들기 위한 타이머 사용을 안내합니다.
- **과목별 분석**은 이번 달 과목별 시간을 비교해 가장 많이·적게 공부한 과목을 표시하고 비중 그래프를 제공합니다. 공부 기록이 없는 과목도 등록된 과목과 비교할 수 있습니다.
- **별이의 한 마디**는 버튼을 눌렀을 때 Gemini가 월간 총 학습 시간, 과목별 학습 시간, 요일·시간대 패턴과 저장된 과목 성적·학점을 바탕으로 조언합니다. 기록에 나타난 사실과 별이의 분석을 함께 제공하며, 응답 위에 별이 이미지를 표시합니다.
- AI 조언은 로그인되어 있고 해당 월에 공부 기록이 있어야 요청할 수 있습니다. 매월 다시 요청할 수 있으며, API 설정·네트워크·모델 응답에 문제가 있으면 오류와 재요청 버튼을 표시합니다.

### 할 일 관리 및 달력

- 월간 달력의 이전 달·다음 달 버튼으로 이동하고 "오늘" 버튼으로 현재 월과 날짜로 돌아올 수 있습니다. 날짜를 선택하면 해당 날짜의 일정이 아래 상세 목록에 표시됩니다.
- 홈의 주간 일정에서 날짜를 눌러도 같은 달력 화면으로 이동합니다. 여러 날에 걸친 일정은 달력에 기간 막대로 표시합니다.
- **개인 일정**은 제목, 시작 날짜, 종료 날짜, 메모를 입력해 추가하거나 수정할 수 있습니다. 종료 날짜를 비우면 하루 일정으로 등록됩니다. 종료 날짜는 시작 날짜와 같거나 이후여야 하며, 최대 366일 범위를 지원합니다. 제목은 120자, 메모는 300자까지 입력할 수 있습니다.
- 개인 일정은 완료 처리하거나 완료를 되돌릴 수 있고, 수정하거나 삭제할 수 있습니다. 완료 상태와 변경 사항은 Firebase에 저장됩니다.
- eClass에서 가져온 할 일도 달력과 홈에서 함께 볼 수 있지만, 개인 일정과 구분되며 앱에서 완료·수정·삭제할 수 없습니다.
- **남은 할 일** 표에는 미완료 항목을 날짜순으로 표시합니다. 사이드바의 숫자 배지는 미완료 할 일 수를 나타냅니다.

### 별이와 대화

- 대화 화면에서 별이에게 자유롭게 메시지를 보내거나 추천 질문을 눌러 바로 요청할 수 있습니다.
- 추천 질문은 오늘 학습 계획 만들기, 마감일 기준 일정 우선순위 정리, 현재 평점에 맞는 학점 향상 전략 제안입니다.
- 별이는 친근한 한국어 반말로 짧게 답하고, 마크다운 없이 일반 문장으로 말하도록 설정되어 있습니다. 응답 생성 중에는 진행 상태를 표시하며, 실패 시 다시 대화할 수 있도록 오류를 보여줍니다.
- 답변의 맥락을 위해 Gemini 요청에 저장된 이름·학과·학년, 평점, 전체 수강 과목의 학기·교수·학점·시간·성적, 할 일의 과목·유형·마감·완료 상태·메모를 포함합니다. 개인정보 및 학습 데이터가 Gemini API로 전송될 수 있으므로 API 사용 전 해당 데이터 처리와 제공자의 정책을 확인하세요.
- 대화 내역은 현재 실행 중인 화면의 대화 문맥에 사용되며 Firebase에 저장되는 채팅 기록이나 최근 대화 보관함은 제공하지 않습니다.


## 요구 사항

- Windows 10/11
- Python 3.10 이상
- Git
- Gemini API 키
- Firebase Realtime Database와 Firebase Admin SDK 서비스 계정 키
- 서울과학기술대학교 eClass 계정

## 설치 및 실행

PowerShell에서 프로젝트를 내려받고 프로젝트 폴더로 이동합니다.

```powershell
git clone https://github.com/<GitHub-사용자명>/<저장소명>.git
cd <저장소명>
py -3.10 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
pip install -r requirements.txt
Copy-Item .env.example .env
```

PowerShell에서 가상 환경 활성화가 차단되면 현재 창에서만 실행 정책을 변경한 다음 다시 활성화합니다.

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
.\.venv\Scripts\Activate.ps1
```

필요한 설정을 마친 뒤 앱을 실행합니다.

```powershell
python main.py
```

## API 및 Firebase 설정

### Gemini

프로젝트 루트의 `.env` 파일을 열고 실제 Gemini API 키를 입력합니다.

```dotenv
GEMINI_API_KEY=여기에_실제_API_키
GEMINI_MODEL=gemini-3.6-flash
```

`GEMINI_MODEL`은 선택 항목입니다. 값을 비워 두면 애플리케이션에 설정된 기본 모델을 사용합니다. 사용할 수 있는 모델과 API 사용량은 본인의 Gemini API 설정에서 확인하세요.

### Firebase

1. Firebase 프로젝트에서 Realtime Database를 설정합니다.
2. 해당 프로젝트의 Firebase Admin SDK 서비스 계정 키(JSON)를 발급합니다.
3. JSON 파일을 프로젝트 루트에 `com-hackathon-firebase-adminsdk-fbsvc-0b2c53509c.json` 이름으로 둡니다.
4. 다른 Firebase 프로젝트를 사용하는 경우 `backend/shared.py`의 `FIREBASE_DATABASE_URL`을 해당 데이터베이스 URL로 변경합니다.

서비스 계정 JSON은 데이터베이스에 대한 관리자 권한을 가질 수 있는 민감한 비밀 파일입니다. GitHub에 올리거나 다른 사람과 공유하지 마세요. `.env`와 서비스 계정 JSON은 `.gitignore`에 등록되어 있습니다.
